# TypeScript Assignment

## Introduction

This repository contains my TypeScript assignment solutions and blog posts. The main purpose of this assignment is to improve my understanding of TypeScript concepts and Object-Oriented Programming (OOP).

## Project Structure

- `solutions.ts` – Contains all coding problem solutions in a single file.
- `type-vs-interface.md` – Explains the differences between Type and Interface.
- `access-modifiers.md` – Explains Public, Private, Protected, and Readonly access modifiers.
- `union-and-intersection-types.md` – Explains how to combine Union and Intersection types.

## Topics Covered

- Type Aliases and Interfaces
- Type Narrowing
- Union and Intersection Types
- Access Modifiers
- Functions and Generics
- Classes and Inheritance
- Promises and Async/Await
